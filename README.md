## 🔭 What I'm working on

**ULTRON** is a JARVIS-style personal AI assistant that runs fully on my own laptop, with no paid APIs.

- 🎙️ Wake word ("Hey Ultron"), local speech-to-text, and a spoken voice
- 💻 Laptop control: apps, volume, lock, screenshots, system status
- 📱 Android control over ADB
- ✋ Hand-gesture control with MediaPipe
- 🗂️ Background job queue with voice approval
- 🏆 One-sentence hackathon package: pitch deck, script, judge Q&A, and a working demo site
